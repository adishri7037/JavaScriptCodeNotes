# 10 Important Theory + Practical Questions

Questions
1. What does document.createElement() do? Does it automatically add the element to the page?
2. Differentiate between append() and appendChild() with examples.
3. What is the purpose of element.remove()?
4. Why is it useful to store UI data as an array of objects?
5. What is a DocumentFragment, and how can it improve repeated DOM insertion?

Coding Questions
6. Write JavaScript to create an <li> dynamically and add it to an existing <ul>.
7. Create a function that receives a product object and returns a complete product-card DOM element.
8. Render five student objects as cards using createElement() and append().
9. Add a Remove button to every dynamically created product card so that only the clicked card is removed.
10. Modify the product-card practical so that all cards are first assembled in a DocumentFragment and then inserted into the page with one DOM operation.
