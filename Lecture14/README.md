# Creating, Inserting & Removing Elements

This folder is prepared for a 7th-semester B.Tech JavaScript/DOM lecture.

## Files
- `01_Theory/lecture_notes.md` - complete lecture theory.
- `02_Concept_Code/index.html` + `script.js` - small concept demonstrations.
- `03_Practical_Product_Cards/index.html` + `style.css` + `script.js` - complete practical.
- `04_Important_Questions/questions.md` - 10 important theory + practical questions.

## How to Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `02_Concept_Code/index.html` in a browser for concept examples.
4. Open `03_Practical_Product_Cards/index.html` in a browser for the practical.
5. Optionally use VS Code Live Server.

## Teaching Goal
Students should understand the complete flow:
JavaScript data -> create DOM nodes -> configure nodes -> insert nodes -> remove nodes.
