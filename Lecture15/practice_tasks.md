# Extra Practice Tasks

## Beginner
1. Print the parent of a selected button.
2. Print all direct children of a section.
3. Display the child count on the page.
4. Find the nearest `.card` using `closest()`.

## Intermediate
5. Build a profile card from an object.
6. Render five skills from an array.
7. Add a delete button to each skill.
8. Use event delegation to remove a skill.
9. Build an FAQ accordion.
10. Add a theme switcher using `classList.toggle()`.

## Advanced
11. Build a profile editor that updates the rendered profile.
12. Add random quote generation.
13. Add a favorite quote button.
14. Store a profile ID using `data-id`.
15. Refactor the complete project into data, logic, and rendering modules.
