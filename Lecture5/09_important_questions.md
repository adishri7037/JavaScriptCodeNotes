# 10 Important Questions — Loops & Problem-Solving Patterns

1. What is a loop in JavaScript, and why is it used?
2. Explain the syntax and execution flow of a `for` loop with an example.
3. Differentiate between `for`, `while`, and `do...while` loops. When would you choose each?
4. What is the difference between `break` and `continue`?
5. What is a nested loop? Write a JavaScript example and explain its execution.
6. Explain `for...of` and `for...in` with examples. What is the key difference between them?
7. What causes an infinite loop? Give an example and explain how to prevent it.
8. Write a program to check whether a number is prime using a loop.
9. Write a JavaScript program using nested loops to generate a right-triangle star pattern.
10. Write a program to generate a number pattern such as:
    1
    12
    123
    1234
    12345
