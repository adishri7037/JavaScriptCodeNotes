# Quick Revision Sheet

- `forEach()` → perform an action for each item.
- `map()` → transform every item → new array.
- `filter()` → select matching items → new array.
- `reduce()` → accumulate/combine → one final result.
- `find()` → first matching element.
- `findIndex()` → index of first matching element.
- `some()` → at least one matches → boolean.
- `every()` → all match → boolean.
- Callback → function supplied to another function.
- Chaining → use the output of one method as input to another.
- Prefer readable code over unnecessarily clever one-liners.
