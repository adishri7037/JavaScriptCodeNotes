# 10 Important Questions
## Array Methods & Higher-Order Thinking

1. What is a higher-order function in JavaScript? Explain with an example using an array method.

2. What is a callback function? How is a callback passed to `forEach()` or `map()`?

3. Differentiate between `forEach()` and `map()`. When should each be used?

4. Explain `filter()` with a suitable example. How is its output different from `find()`?

5. Explain `reduce()` using an example to calculate the total and average of student marks.

6. What is the difference between `find()` and `findIndex()`? What do they return when no matching element exists?

7. Differentiate between `some()` and `every()` with examples.

8. What is method chaining? Write a chain using `filter()` and `map()` to obtain names of students scoring 75 or above.

9. Given a sales array containing `product`, `price`, and `quantity`, write JavaScript to calculate total sales using `reduce()`.

10. For each situation, choose the most suitable method and justify your choice:
   - Print all items.
   - Transform all items.
   - Select matching items.
   - Calculate one total.
   - Find the first matching item.
   - Check whether at least one item matches.
   - Check whether all items match.
