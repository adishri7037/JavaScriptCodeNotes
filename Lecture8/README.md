# Array Methods & Higher-Order Thinking — Lecture ZIP

This folder contains complete concept notes, runnable JavaScript examples, practical exercises, and 10 important questions for a 7th-semester JavaScript lecture.

## Files

1. `01_lecture_notes.md` — complete lecture concepts and examples.
2. `02_marks_analysis.js` — practical student marks analyzer.
3. `03_sales_analysis.js` — practical sales-data analyzer.
4. `04_method_selection_practice.js` — method-selection examples.
5. `05_important_questions.md` — 10 important questions.
6. `06_assignment.md` — hands-on assignment.
7. `07_quick_revision.md` — quick revision sheet.

## How to Run

Open the folder in VS Code.

Make sure Node.js is installed, then run:

```bash
node 02_marks_analysis.js
node 03_sales_analysis.js
node 04_method_selection_practice.js
```

The Markdown files can be opened directly in VS Code for teaching and revision.
