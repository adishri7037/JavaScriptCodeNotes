# Classes, Inline Styles & Visual State — JavaScript DOM Lecture

B.Tech 7th Semester JavaScript lecture/practical package.

## Topic Coverage
- className vs classList
- classList.add(), remove(), toggle(), contains(), replace()
- Reading and setting style properties
- CSS classes as the preferred visual-state mechanism
- Show/hide patterns and accessibility
- Theme-switching architecture
- Practical: Theme Changer + Expandable FAQ
- 10 important theory/practical questions

## How to Run
Open `practical/index.html` in a browser, preferably with VS Code + Live Server.
Open browser DevTools Console to observe messages.

## Folder Structure
- `01-classname-vs-classlist/` — core concepts
- `02-classlist-methods/` — add/remove/toggle/contains/replace
- `03-inline-styles/` — reading and setting style properties
- `04-css-classes-state/` — state through CSS classes
- `05-show-hide-accessibility/` — accessible show/hide patterns
- `06-theme-switching/` — theme architecture
- `practical/` — complete Theme Changer + Expandable FAQ
- `questions/` — important questions
