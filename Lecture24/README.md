# ES Modules & Code Organization — JavaScript Study Pack

Includes detailed notes, runnable examples, interview questions, and a practice project refactored into focused ES modules.

## Run it
Extract the ZIP and serve this folder with a local HTTP server. ES modules loaded by `<script type="module">` often fail when opened directly with `file://` due to browser security/CORS rules.

Examples:
- VS Code: use the Live Server extension and open `index.html`
- Python: run `python -m http.server 8000` in this folder, then visit `http://localhost:8000`

The project stores sample tasks in browser localStorage.
