# Callbacks & Callback Hell — JavaScript Study Pack

This ZIP contains detailed concept notes, runnable code examples, important interview questions with answers, and a multi-step order/registration simulator.

## Contents
- `01-Concept-Notes.md` — callbacks, function arguments, sync/async callbacks, error handling, callback hell, debugging
- `02-Examples/` — focused JavaScript snippets
- `03-Practice-Project/order-registration-simulator.html` — interactive multi-step simulator
- `04-Important-Questions.md` — interview questions, output prediction, and practice challenges
- `index.html` — launcher for the practice project and study files

## How to use
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Read the concept notes and run the examples in a browser DevTools Console or Node.js where indicated.
4. Complete the challenge exercises without looking at the answers first.

The simulator uses mocked asynchronous steps; it does not submit real orders or register real accounts.
