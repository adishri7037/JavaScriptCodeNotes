3. What is reassignment? Which variable declarations allow reassignment?
4. What are JavaScript primitive data types? Give examples.

6. What does the `typeof` operator do? Explain the special cases `typeof null` and `typeof NaN`.
7. What is `NaN`? How can you check whether a value is NaN?
8. What is the difference between explicit type conversion and implicit type coercion?
9. What are truthy and falsy values? List the main falsy values in JavaScript.
