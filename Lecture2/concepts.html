JavaScript Variables, Data Types & Type Conversion

1. Variables

A variable is a named storage location used to hold a value. JavaScript provides var, let, and const.

let studentName = "Rahul";
let age = 21;
console.log(studentName, age);

2. var, let and const

var

var age = 20;
age = 21;          // allowed
var age = 22;      // redeclaration allowed
console.log(age);

let

let score = 50;
score = 80;        // allowed
// let score = 90; // error: cannot redeclare in same scope

const

const pi = 3.14159;
// pi = 3.14;      // error: reassignment is not allowed

Important: const prevents reassignment of the variable. It does not make an object or array immutable.

const student = { name: "Rahul", age: 21 };
student.age = 22; // allowed

// student = { name: "Amit" }; // not allowed

3. Naming Conventions

  • Use meaningful names.
  • Use camelCase for normal JavaScript variables.
  • Do not start with a digit.
  • No spaces are allowed.
  • Do not use reserved keywords.
let firstName = "Rahul";
let totalMarks = 450;
let isLoggedIn = true;
let studentCount = 60;

4. Reassignment

let marks = 70;
marks = 85;
console.log(marks); // 85

Reassignment changes the value stored in an existing variable.

5. Primitive Values

JavaScript primitive types include string, number, bigint, boolean, undefined, symbol, and null.

let name = "Aditya";        // string
let age = 21;               // number
let price = 99.99;          // number
let active = true;          // boolean
let result;                 // undefined
let empty = null;           // null
let large = 123n;           // bigint
let id = Symbol("id");      // symbol

6. Reference Types

Objects, arrays and functions are reference values. Multiple variables can refer to the same object.

let student1 = { name: "Rahul" };
let student2 = student1;

student2.name = "Amit";

console.log(student1.name); // Amit

Conceptually:

student1 ──┐
           ├──> { name: "Amit" }
student2 ──┘

7. typeof Operator

console.log(typeof "Hello");      // string
console.log(typeof 42);            // number
console.log(typeof true);           // boolean
console.log(typeof undefined);      // undefined
console.log(typeof {});             // object
console.log(typeof []);             // object
console.log(typeof function() {});  // function

Special case: null

console.log(typeof null); // "object"

This is a historical JavaScript quirk. null represents intentional absence of a value; it should not be taught as an actual object.

Special case: NaN

let result = 10 / "hello";
console.log(result);              // NaN
console.log(typeof result);       // number
console.log(Number.isNaN(result)); // true

NaN means "Not-a-Number" and is a special value of the JavaScript number type.

8. Explicit Type Conversion

The programmer intentionally converts a value.

let text = "100";
let number = Number(text);

console.log(number);        // 100
console.log(typeof number); // number

console.log(String(21));    // "21"
console.log(Boolean(1));    // true

9. Implicit Type Coercion

JavaScript automatically converts values during some operations.

console.log("10" + 5); // "105"
console.log("10" - 5); // 5
console.log("10" * 2); // 20

The + operator can concatenate strings, while arithmetic operators such as - and * coerce numeric strings to numbers.

10. Truthy and Falsy Values

When a value is used in a Boolean context, JavaScript treats it as truthy or falsy.

Main falsy values:

false
0
-0
0n
""
null
undefined
NaN

Examples of truthy values include non-empty strings, non-zero numbers, arrays, objects, and true.

console.log(Boolean("Hello")); // true
console.log(Boolean("0"));     // true
console.log(Boolean(0));       // false
console.log(Boolean([]));      // true
console.log(Boolean({}));      // true

11. Practical Login Example

let username = "";

if (username) {
  console.log("Username entered");
} else {
  console.log("Please enter username");
}

12. == vs ===

console.log(5 == "5");  // true: coercion occurs
console.log(5 === "5"); // false: type and value must match

In most application code, prefer strict equality (=== and !==) to avoid unexpected coercion.

13. Classroom Quick Revision

  • var: function-scoped, can be reassigned and redeclared.
  • let: block-scoped, can be reassigned, cannot be redeclared in the same scope.
  • const: block-scoped, cannot be reassigned, must be initialized.
  • typeof null: "object" due to a historical quirk.
  • typeof NaN: "number".
  • Explicit conversion: Number(), String(), Boolean().
  • Implicit coercion: JavaScript automatically converts types.
  • Falsy: false, 0, -0, 0n, "", null, undefined, NaN.
  • Truthy: almost everything else, including [] and {}.
