# Practice Exercises

Exercise 1: Character Frequency
Write a function that accepts a string and returns an object containing the frequency of each character.

Example:
Input: `hello`
Output: `{ h: 1, e: 1, l: 2, o: 1 }`

Exercise 2: Word Analysis
Given a sentence:
- count words
- find the longest word
- count repeated words

Exercise 3: Student Search
Extend the project to search students by:
- ID
- exact name
- partial name
- course

Exercise 4: Reports
Add:
- minimum average
- maximum average
- subject-wise average
- grade distribution

Exercise 5: Validation
Prevent:
- duplicate IDs
- empty names
- marks below 0
- marks above 100
- non-numeric marks

Exercise 6: Edge Cases
Test:
- empty student list
- one student
- duplicate names
- search with uppercase/lowercase differences
- search with extra spaces
- student with a single mark
