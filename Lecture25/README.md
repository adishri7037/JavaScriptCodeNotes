# Closures, Higher-order Functions & Functional Patterns

A complete JavaScript learning package with concept notes, runnable examples, interview questions, and a hands-on practice project.

## Contents
- `01-Concept-Notes.md` — detailed explanations, examples, common pitfalls, and best practices
- `02-Examples/closures.js` — lexical scope, private state, counters, configuration
- `02-Examples/higher-order-functions.js` — functions as arguments/return values, map/filter/reduce
- `02-Examples/functional-patterns.js` — pure functions, immutability, composition
- `03-Practice-Project/` — configurable validators and private counter
- `04-Important-Questions.md` — interview questions with concise answers

## Run the examples
Install Node.js if needed, then run from this folder:

```bash
node 02-Examples/closures.js
node 02-Examples/higher-order-functions.js
node 02-Examples/functional-patterns.js
node 03-Practice-Project/app.js
```

The examples use standard JavaScript and CommonJS-compatible syntax for easy execution with Node.js. You can also adapt them to browser modules.

## Suggested study order
1. Read lexical scope and closures.
2. Run `closures.js` and predict the output before executing.
3. Study higher-order functions.
4. Practice composition and pure functions.
5. Complete the validator and private-counter task without looking at the solution first.
6. Answer the interview questions aloud.
