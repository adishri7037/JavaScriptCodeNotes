# Promises & Error Handling — JavaScript Study Pack

This package contains detailed concept notes, code examples, interview questions with answers, and two practice projects: a Promise-based task runner and a simulated login flow.

## Contents
- `01-Concept-Notes.md` — Promise states, then/catch/finally, chaining, propagation, recovery
- `02-Examples/` — runnable JavaScript snippets
- `03-Practice-Projects/task-runner.html` — sequential Promise-based task runner
- `03-Practice-Projects/simulated-login.html` — simulated login flow with validation and error recovery
- `04-Important-Questions.md` — interview questions, output predictions, coding challenges
- `index.html` — launcher page

## How to use
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Read the notes and run JavaScript snippets in a browser DevTools Console or Node.js where appropriate.
4. Try the practice projects, including their failure/retry options.

**Security note:** The login app is a front-end learning demo only. It does not authenticate against a server and must not be used to protect real accounts or collect real passwords.
