# 10 Important Questions — Conditionals & Decision Logic

1. What are conditional statements in JavaScript, and how do `if`, `else if`, and `else` work? Give a suitable example.

2. Explain the syntax and working of a `switch` statement. Why is the `break` statement commonly used?

3. Differentiate between `if...else if...else` and `switch`. When would you choose each?

4. What is the ternary operator? Convert a simple `if...else` statement into a ternary expression.

5. What is nested decision logic? Write an example and explain two ways to improve readability of deeply nested conditions.

6. What is a guard clause? Explain how guard clauses can reduce nesting in a JavaScript function.

7. Differentiate between `=`, `==`, and `===` in JavaScript. Why is `===` generally preferred for equality checks?

8. Explain JavaScript type coercion with an example such as `5 == "5"` and `5 === "5"`.

9. Why is `18 <= age <= 60` incorrect for checking a range in JavaScript? Write the correct expression.

10. Write a JavaScript program that validates marks from 0–100 and prints grades using `if...else if...else`, including proper handling of invalid input.
