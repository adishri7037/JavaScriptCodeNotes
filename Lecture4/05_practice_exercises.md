Practice Exercises

Exercise 1 Grade Calculator
Accept a marks value and print:
* 90 - 100: A+
* 80 - 89: A
* 70 -79: B
* 60 - 69: C
* 40 - 59: D
* 0 - 39: F
* Outside 0 -100: Invalid

Exercise 2 -  Day Selector
Use switch to print whether a day is a weekday or weekend.

Exercise 3 - Login Access
Create a function that uses guard clauses to reject:
* missing username
* incorrect password
* inactive account

Return a useful message for each case.

Exercise 4 - Range Validation
Write conditions for:
1. age between 18 and 60 inclusive
2. marks outside 0–100
3. temperature below 0 or above 40

Exercise 5 - Ternary Practice
Use ternary expressions for:
1. pass/fail
2. adult/minor
3. logged-in/logged-out
