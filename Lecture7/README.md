# JavaScript Arrays: Creation, Access & Mutation

## 7th-Semester Lecture Practice Pack

### Topics Covered
1. Creating arrays and accessing elements by index
2. `length` and iteration
3. `push()`, `pop()`, `shift()`, `unshift()`, `splice()` and `slice()`
4. `indexOf()`, `includes()` and `find()` basics
5. Mutable vs non-mutating operations
6. Arrays of records (objects)
7. Hands-on: Console-based Student List Manager

## How to Run
### Browser
Open `index.html` with a browser and press F12 -> Console.

### Node.js
Open the folder in VS Code and run:
```bash
node student-list-manager.js
```

The examples are intentionally separated into small concepts so they can be demonstrated during a lecture.
